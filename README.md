# 🛍️Product Splash Page
Product Splash Page is a responsive, static landing page designed to promote a single product. Built entirely with HTML and CSS, this project demonstrates modern web layout practices and mobile-friendly design without any JavaScript. This project simulates a product marketing page featuring a visually engaging layout, bold call-to-action elements, and a clean presentation. It’s ideal for practice with static site structure, typography, responsive images, and styling.

## ⚙️Tech Stack
- HTML
- CSS
